# Online Bookstore SQL Analysis

## Project Overview

This project analyzes an online bookstore dataset using MySQL to explore
sales performance, customer behavior, book inventory, genres, and revenue.


## Tools & Technologies

- MySQL
- MySQL Workbench

## Dataset

The dataset contains three main tables:

- Books
- Customers
- Orders

## Key Insights
Books generating the highest revenue
total revenue generated from orders
Customer purchasing behavior
Order trends over time
Stock availability analysis


## SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- BETWEEN
- ORDER BY
- LIMIT
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- SUM()
- AVG()
- COUNT()
- COALESCE()
